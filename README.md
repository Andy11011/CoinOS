# CoinOS

A lightweight OS for deploying and running algorithmic trading systems.

## Features

- Lightweight Raspberry Pi OS base
- Algotrading node ready
- Automated builds with Jenkins

## Building

### Prerequisites

- Jenkins with Docker support

### Build Steps

1. Clone this repository
2. Initialize submodules: `git submodule update --init`
3. Run Jenkins pipeline or manual build

## Configuration

See `configs/` directory for image profiles.
